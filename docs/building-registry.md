## หลักการ normalize

location ที่ผู้ใช้พิมพ์มักมี **หน่วยย่อย/ชั้น/ห้อง** ต่อท้ายหรือนำหน้า เช่น
`"ตึก 72 ปี ธนาคารเลือด"`, `"ห้องยา ตึกผู้ป่วยนอก"` → ต้อง map กลับเป็นอาคารหลัก

**อัลกอริทึม:** ตัดช่องว่างหัวท้าย → เช็ค exact-map → เช็ค substring (ชื่อยาวชนะก่อน) → ถ้าไม่ตรงเลย = `อื่นๆ (นอกทะเบียน)` · ค่าว่าง/`ไม่ระบุ` = `ไม่ระบุ`

## จุดที่ต้องระวัง (ambiguous) — ตัดสินใจแล้ว

- **"หอพักพยาบาล" เดี่ยว (ไม่มีเลข)** → นับเป็น **หอพักพยาบาล 1**
- **หอพักนักศึกษาแพทย์ vs ตึกปฏิบัติการสารสนเทศ** → **แยกเป็น 2 อาคาร**
- **ตึกวางแผนครอบครัว** → เก็บเป็นอาคารแยก (แม้ไม่อยู่ในทะเบียน 67)
- **นอกทะเบียน** (EMS/แพทย์ฉุกเฉินหอพักเจ้าพระยา, รร.กายอุปกรณ์, อาคาร A/B, ตึก 8 ไร่) → รวมเป็น **"อื่นๆ (นอกทะเบียน)"**
